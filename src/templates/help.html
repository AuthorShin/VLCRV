VLC REMOTE CONTROL

Commands sent to VLC over your local network.

Format

Each field is command or command|val. Example: seek|+10s jumps 10 seconds forward.

Useful commands

pl_play, pl_pause, pl_stop, pl_next, pl_previous, fullscreen, volume, seek, key, rate, snapshot.

Key names

For key: play-pause, vol-mute, toggle-fullscreen, quit, jump+short, jump-short.

Volume / seek values

volume: +10, -10, 128, 50%. seek: +10s, -10s, 50%.

Requirements

VLC on the target PC must have its Web interface enabled and the same password as VLC_HTTP_PASSWORD. Nothing here needs internet access.
